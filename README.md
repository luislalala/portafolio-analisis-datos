Bienvenido a mi portafolio. Como estudiante de **Física en la UNAM**, abordo el análisis de datos bajo una metodología lógica, rigurosa y orientada a la resolución de problemas complejos. Este repositorio compila proyectos que demuestran mi flujo de trabajo completo: desde la limpieza de datos hasta la comunicación de hallazgos estratégicos.

---

## 🚀 Proyectos Destacados

### 1. Análisis Estratégico: Transporte Ferroviario (Power BI & LaTeX)
Este proyecto se enfoca en la visualización de datos operativos y la toma de decisiones basada en métricas financieras.
* **Enfoque:** Optimización logística, análisis de estacionalidad y arquitectura de precios (Efecto Señuelo).
* **Entregables:**
    * `trains.pbix`: Dashboard interactivo diseñado en **Power BI**.
    * `analisis de trains.pdf`: Reporte técnico redactado en **LaTeX**, que presenta las propuestas de mejora estratégica con rigor académico.

### 2. Análisis Exploratorio de Retail (Python & Data Storytelling)
Análisis del dataset *SampleSuperstore* aplicando principios de economía y negocio.
* **Enfoque:** Identificación de productos clave mediante la **Regla de Pareto (80/20)** para maximizar la rentabilidad.
* **Tecnologías:** Jupyter Notebooks, Pandas, Matplotlib.
* **Archivo:** `mi_analisis.ipynb`

### 3. Fundamentos de Ciencia de Datos (Python Scripting)
Ejercicios de desarrollo lógico, manipulación de estructuras de datos y Programación Orientada a Objetos (POO).
* **Áreas:** * `ejsnumpy.py`: Manipulación de matrices, covarianza y correlación estadística.
    * `ejspandas.py`: Limpieza de datos, manejo de nulos y agrupación avanzada.
    * `ejspoo.py`: Modelado de sistemas mediante POO para entornos empresariales.
